# Vue Authentication Module – Week 4

## UI/UX Integration & Responsive Design

This project extends the Vue authentication application with a self-created responsive UI/UX design.

### Improvements
- Responsive authentication pages and dashboard
- Reusable header/footer/cards
- Mobile navigation menu
- CSS Grid + Flexbox + media queries
- Accessible focus and form states
- Fluid typography with `clamp()`
- Reduced-motion support
- Consistent design tokens

### Run
```bash
npm install
npm run dev
```
Build:
```bash
npm run build
```

## Week 5 – Unit Testing & Quality Assurance

The project now includes automated unit tests using Vitest and Vue Test Utils. Tests cover reusable Vue components, validation utilities, storage helpers, safe redirects, and the Pinia authentication store.

### Run tests
```bash
npm install
npm test
```

### Watch tests
```bash
npm run test:watch
```

### Coverage
```bash
npm run test:coverage
```

See `WEEK5_UNIT_TESTING_REPORT.md`, `TEST_CASES.md`, and `QA_TESTING_REPORT.md` for the Week 5 documentation.
